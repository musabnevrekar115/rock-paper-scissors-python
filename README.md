# ✊ Rock-Paper-Scissors Game

An interactive desktop game built with Python and Tkinter. Play against the computer using emoji buttons or keyboard shortcuts.

## Features

- Player vs computer gameplay
- Rock, Paper and Scissors emoji buttons
- Countdown animation
- Score tracking for wins, losses and ties
- Recent round history
- Keyboard shortcuts: R, P and S
- Reset button to start fresh

## Technologies

- Python 3
- Tkinter for the graphical interface
- random module for computer moves

## How to Run

1. Install Python 3 with Tkinter support.
2. Download this repository and extract it.
3. Open a terminal in the project folder.
4. Run:

```bash
python rock_paper_scissors.py
```

## How to Play

Choose a move using the buttons or keyboard:

| Key | Move |
|-----|------|
| R | Rock |
| P | Paper |
| S | Scissors |

Rock beats Scissors, Scissors beats Paper, and Paper beats Rock. Identical choices result in a tie.
